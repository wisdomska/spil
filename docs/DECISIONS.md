# Decisions

Decisions not covered by docs/TECH_SPEC.md, the SRS or the design. Newest last.

| Date       | Decision                                                                                                                                                                                                                                                                       | Why                                                                                                                                                                                                                                                                |
| ---------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 2026-10-22 | Next.js 16.4 (latest stable) instead of 15                                                                                                                                                                                                                                     | Spec says "15+, latest stable"; 16 is current.                                                                                                                                                                                                                     |
| 2026-10-22 | Staging Supabase project is named `spil-preview` (spec section 4 says `spil-staging`)                                                                                                                                                                                          | Matches the `preview` branch name the owner chose.                                                                                                                                                                                                                 |
| 2026-10-22 | Licence: all rights reserved, `UNLICENSED` in package.json                                                                                                                                                                                                                     | Owner default.                                                                                                                                                                                                                                                     |
| 2026-10-22 | Repo is private                                                                                                                                                                                                                                                                | Owner choice. E2E full suite runs nightly to stay inside the 2,000 free Actions minutes.                                                                                                                                                                           |
| 2026-10-22 | Node 24 LTS (`.nvmrc`, Vercel `24.x`) instead of Node 20                                                                                                                                                                                                                       | Node 20 reached end of life in April 2026; 24 is the current LTS and Vercel's default.                                                                                                                                                                             |
| 2026-10-22 | Rebase merges only, branches squashed locally first                                                                                                                                                                                                                            | GitHub authors squash and merge commits itself ("Senya" noreply address). Local squash keeps `wisdomska(senya)` as the only author.                                                                                                                                |
| 2026-10-22 | Dependabot PRs are adopted as owner-authored commits, never merged                                                                                                                                                                                                             | Bot-authored commits would break the single-author rule.                                                                                                                                                                                                           |
| 2026-10-22 | Supabase projects in eu-west-2 (London), Vercel functions in `lhr1`                                                                                                                                                                                                            | Closest free-tier regions to West Africa; same region keeps DB round trips short.                                                                                                                                                                                  |
| 2026-10-22 | Where `SPIL App.dc.html` and `SPIL Prototype.dc.html` differ, App wins (floating pill header, interactive hero, host-chosen question count, pack info sheets, landing share-card demo); the Prototype's landing theme toggle is kept because the spec requires a theme menu    | App is the later iteration of the same prototype; the Screens files still render the older Prototype, so visual parity diffs on those frames are reviewed against App behaviour                                                                                    |
| 2026-10-22 | Host picks the question count on the pack picker (5, 10, 15, 20, 30, 50, All), defaulting to the admin `questions_per_game` setting                                                                                                                                            | The App prototype ships this picker; the admin setting becomes the default rather than a fixed value                                                                                                                                                               |
| 2026-10-22 | Fixed print colours (avatar ink and plate, adult heat tiles, 18+ badge, paper pack tiles) live in `app/styles/spil-extras.css` as variables                                                                                                                                    | They appear in the design but are not theme tokens; keeping them in `app/styles` keeps components hex-free and `tokens.css` unchanged                                                                                                                              |
| 2026-10-22 | Avatars are ported as React components using the design's CSS gradients, not SVG                                                                                                                                                                                               | The design builds avatars from CSS gradients; porting them exactly is the faithful option                                                                                                                                                                          |
| 2026-10-22 | `cacheComponents` and `partialPrefetching` stay on (Next 16 scaffold defaults)                                                                                                                                                                                                 | Faster navigations; dynamic data is wrapped in Suspense                                                                                                                                                                                                            |
| 2026-10-22 | Players who sat out answering can still guess, and their guesses count toward the room's guess about others                                                                                                                                                                    | The force-next sheet copy promises "They can still guess."; they have no score of their own                                                                                                                                                                        |
| 2026-10-22 | Public email sign-up is off; admins are created by the owner with the service role. Anonymous sign-in stays on                                                                                                                                                                 | Only admins have email accounts; open sign-up would let anyone create one                                                                                                                                                                                          |
| 2026-10-22 | Anonymous sign-ins raised to 200/hour per IP (sign-ins 100/hour)                                                                                                                                                                                                               | A venue's shared Wi-Fi puts many phones behind one IP; 30/hour would block a busy night                                                                                                                                                                            |
| 2026-10-22 | Admin password reset accepts the 6-digit code and Supabase's default reset link                                                                                                                                                                                                | Free projects on the default mail provider cannot change templates; the code email needs custom SMTP (open item)                                                                                                                                                   |
| 2026-10-22 | JWTs verified locally with `getClaims` (ES256 JWKS)                                                                                                                                                                                                                            | Saves an auth round trip on every API request                                                                                                                                                                                                                      |
| 2026-10-22 | `partialPrefetching` is off                                                                                                                                                                                                                                                    | With it on, Next 16.4 dev servers reload the page in a loop (every render triggers a rebuild); the gain is small for this app                                                                                                                                      |
| 2026-10-22 | Hide-my-name on the story card prints "My Spill Score" and drops the avatar (design), not "Anonymous player" (spec 16)                                                                                                                                                         | The design's card copy reads naturally and still hides the player                                                                                                                                                                                                  |
| 2026-10-22 | Pack glyphs come from a fixed list of Phosphor icons (`components/brand/PackGlyph.tsx`)                                                                                                                                                                                        | Admins pick an icon by name; a fixed list keeps the bundle small and every name valid                                                                                                                                                                              |
| 2026-10-22 | OG images use static Bricolage 800, Geist 500 and Geist Mono 600 files in `assets/fonts`                                                                                                                                                                                       | Satori cannot read woff2 or variable fonts                                                                                                                                                                                                                         |
| 2026-10-23 | Reveal clients start at `revealed_at` with at most 2 s of catch-up; anyone arriving after the full ceremony goes straight to results                                                                                                                                           | Spec section 8 (max 2 s skew); a slow reveal request must never skip players                                                                                                                                                                                       |
| 2026-10-23 | The reveal is a pure timeline function (`lib/room/revealTimeline.ts`) driven by one rAF loop writing to Motion values                                                                                                                                                          | HANDOFF: no React state per frame; makes the beats unit-testable                                                                                                                                                                                                   |
| 2026-10-23 | Lobby sticker tilt uses the player's seeded rotation (`rotationFor`), other sticker lists use the prototype's index rotation                                                                                                                                                   | Spec 13.1 for players; prototype values elsewhere                                                                                                                                                                                                                  |
| 2026-10-23 | Admin sign-in is a POST route (`/api/v1/admin/login`) that signs in on the server with the anon key and sets the session cookie through `@supabase/ssr`, then checks `admins`. Non-admins get the same "email and password do not match" answer and their session is dropped   | Rate limit (5 per 15 min per IP) and the allow-list check happen before the browser holds a session; no client-side auth state to keep in sync                                                                                                                     |
| 2026-10-23 | `proxy.ts` sends signed-out visitors and non-admins (`is_admin()` RPC) from `/admin/*` to `/admin/login`, and signed-in admins away from the login page; the console layout repeats the check on the server, and every admin route checks the role again with the service role | Clean redirects before render, plus defence in depth                                                                                                                                                                                                               |
| 2026-10-23 | Admin passwords need at least 10 characters (design copy says 8)                                                                                                                                                                                                               | `supabase/config.toml` sets `minimum_password_length = 10`; the copy follows the real rule                                                                                                                                                                         |
| 2026-10-23 | Settings ranges follow the database and spec 2 (questions 5 to 100, players 3 to 20, max at least min), not the prototype's 5 to 50 and 2 to 24                                                                                                                                | The prototype's ranges would be rejected by the table checks                                                                                                                                                                                                       |
| 2026-10-23 | "Reset all data" (owner, not in production) wipes rooms, reports, messages and play stats and zeroes question counters; it does not restore seed content. Copy changed to say so                                                                                               | The app has no copy of the seed; `supabase db reset` restores content locally                                                                                                                                                                                      |
| 2026-10-23 | Removing an admin deletes their auth user too; an owner cannot change, reset or remove their own account from the list, and the last owner cannot be demoted or removed                                                                                                        | Admin accounts exist only for the console; the console must never lock everyone out                                                                                                                                                                                |
| 2026-10-23 | Packs and questions that a room still references cannot be deleted (409 `PACK_IN_USE` / `QUESTION_IN_USE`); hide them instead. Rooms are deleted after 7 days, after which delete works                                                                                        | Foreign keys from rooms, room_questions and answers; keeps finished games readable                                                                                                                                                                                 |
| 2026-10-23 | The audit log stores action keys (`pack_edited`, ...) with before/after jsonb; the console shows labels from `messages/en.json`. Sign-in, sign-out and password resets are logged too                                                                                          | All UI copy stays in en.json; keys are stable if wording changes                                                                                                                                                                                                   |
| 2026-10-23 | Inbox actions are Reply (mailto), Mark read / unread and Archive / Restore; there is no delete. Reports filter Open, Actioned, Dismissed, All                                                                                                                                  | Spec 17 lists mark read and archive, and report statuses open/actioned/dismissed; the prototype's Delete is dropped                                                                                                                                                |
| 2026-10-23 | CSV import is all or nothing (any bad row: nothing is written, line numbers returned); the export (`pack_id, pack, question, status, answered, yes_rate, reports`) is itself a valid import file. Cells that start with `= + - @` are written with a leading apostrophe        | Safe re-runs, round-trip editing in a spreadsheet, and no formula injection                                                                                                                                                                                        |
| 2026-10-23 | Moderators do not see the Packs section (they can read pack names for the Questions filter)                                                                                                                                                                                    | Spec 17 gives Packs to owner and content lead only                                                                                                                                                                                                                 |
| 2026-10-23 | `[auth.email] enable_signup` in `supabase/config.toml` is now `true`                                                                                                                                                                                                           | The CLI maps it to the email provider switch (`external_email_enabled`); with it off, password sign-in and recovery fail with "Email logins are disabled". Public email sign-ups become possible but such users hold no rights (not in `admins`); see open item 10 |
